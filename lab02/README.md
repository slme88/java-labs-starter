# Лабораторная работа № 2: Классы и инкапсуляция

## Инварианты классов

### 1. BankAccount
- Баланс (`balance`) никогда не может принимать отрицательное значение ($balance \ge 0$).
- Операции пополнения (`deposit`) и списания (`withdraw`) возможны только на строго положительную сумму ($amount > 0$).
- Списание не может превышать текущий остаток на счете ($amount \le balance$).

### 2. DataSample (Вариант ИСИИ)
- Идентификатор (`id`) и метка (`label`) обязательны: не равны `null` и не являются пустой строкой.
- Статус (`status`) и массив признаков (`features`) не могут быть `null`.
- Массив признаков инкапсулирован: защитное копирование предотвращает его изменение извне через конструктор или геттер.
